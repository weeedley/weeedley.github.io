3. Hosting and server log files

This website is hosted on GitHub Pages, provided by GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA (part of the Microsoft group).

When you visit the website, GitHub automatically processes technical data sent by your browser, in particular:

This is technically necessary to deliver the website and to keep it secure and stable (e.g. to defend against attacks). The legal basis is Art. 6(1)(f) GDPR; my legitimate interest is providing a secure, working website. I have no access to these log files myself and do not combine them with any other data.

Data may be transferred to the USA. According to GitHub, such transfers are based on the EU-U.S. Data Privacy Framework and on the European Commission's Standard Contractual Clauses. GitHub decides how long the data is stored. For details, see GitHub's privacy statement: GitHub General Privacy Statement.
